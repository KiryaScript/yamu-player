# YAMU 🎵 (WIP / Pre-Alpha)

**YAMU** (Yet Another Music Utility) — это экспериментальный десктопный клиент для Яндекс Музыки.

⚠️ **Статус проекта: Ранняя стадия разработки.**
Приложение находится в активной фазе создания. Возможны баги, нестабильная работа и резкие изменения в интерфейсе. Мы строим "космолет", но пока прикрутили только двигатели и кресло пилота.

![YAMU WIP](https://drive.google.com/file/d/1BSEJDFjE-nuPFyu2z1U56Goafr-_i-un/view?usp=sharing)

## 🚀 Что уже работает

На данный момент реализовано ядро функционала:

* **✅ Авторизация:** Вход через аккаунт Яндекс (Cookies).
* **🎧 Звуковой движок:** Воспроизведение треков, регулировка громкости.
* **🎛️ Эквалайзер:** 10-полосный эквалайзер + нормализация громкости (компрессор).
* **🎮 Discord Rich Presence:** Отображение текущего трека в статусе Discord.
* **❤️ Лайки:** Доступ к коллекции "Мне нравится".
* **🔍 Поиск:** Базовый поиск по трекам.
* **🛠 Настройки:** Очистка кэша, переключение качества (HQ), аппаратное ускорение.

## 🛠 Технический стек

* **Electron** — контейнер приложения.
* **React + Vite** — быстрый UI.
* **TailwindCSS** — стилизация.
* **Web Audio API** — обработка звука (EQ, визуализация).

## 🧑‍💻 Запуск для разработчиков

Если хочешь поковырять код или помочь с разработкой:

1.  **Клонируй репозиторий:**
    ```bash
    git clone [https://github.com/KiryaScript/yamu-player.git](https://github.com/KiryaScript/yamu-player.git)
    cd yamu-player
    ```

2.  **Установи зависимости:**
    ```bash
    npm install
    ```

3.  **Запусти в режиме отладки:**
    ```bash
    npm start
    ```

4.  **Сборка (Build):**
    Чтобы собрать `.exe` для тестов:
    ```bash
    npm run dist
    ```
