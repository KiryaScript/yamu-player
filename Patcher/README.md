## 🌟 Основные возможности

### 🎮 Discord Rich Presence (RPC)
* Отображение текущего играющего трека, исполнителя и названия альбома в вашем профиле Discord.
* Живой динамический прогресс-бар воспроизведения с точным таймкодом.
* Автоматическая загрузка оригинальных HD-обложек треков.
* Интерактивная кнопка **«Слушать трек»** для друзей в Discord.
* Поддержка треков из любых разделов: «Моя волна», плейлисты, альбомы, радио и поиск.

### 📥 Встроенный загрузчик треков, альбомов и плейлистов
* Моментальное сохранение текущего трека по горячей клавише `Ctrl + D` или кнопке в нижней панели плеера.
* Индивидуальные аккуратные кнопки скачивания для каждого трека в списках воспроизведения, альбомах и плейлистах.
* Скачивание целых альбомов и плейлистов (включая «Мне нравится») с сохранением нумерации треков и многодисковых изданий.
* Выбор формата и качества: **FLAC (Lossless)**, **MP3 (320 kbps)**, **MP3 (192 kbps)**.
* Автоматическое вшивание ID3v2-тегов (название, артист, альбом, год, номер дорожки) и HD-обложек прямо в аудиофайлы.

### 📦 Экспорт, бэкап и перенос медиатеки
* **Экспорт в 4 популярных формата:**
  * **Текстовый список (.txt)** — наглядный список `Исполнитель - Название` для заметок.
  * **Таблица (.csv)** — детальная таблица для Excel / Google Таблиц.
  * **Плейлист (.m3u8)** — готовый файл для внешних аудиоплееров (AIMP, VLC, Foobar2000).
  * **Полный бэкап (.json)** — исчерпывающий архив коллекции со всеми идентификаторами и метаданными.
* **Молниеносный перенос между аккаунтами:**
  * Перенос треков большими пачками по 50 штук за раз — вся коллекция перемещается за несколько секунд.
  * Выбор назначения: добавление в «Мне нравится» либо создание нового отдельного плейлиста в один клик.
  * Умный поиск треков в каталоге и наглядный индикатор реального прогресса добавления.

### 🖤 AMOLED True Black Тема
* Настоящий глубокий чёрный цвет (`#000000`) для экранов OLED/AMOLED.
* Применяется ко всем страницам, боковой панели, шапке, фонам плеера и модальным окнам.

### ⚙️ Центр управления модом (Mod Center)
* Вызов окна настроек горячими клавишами `Ctrl + M` или `F2`, а также кнопкой в левой панели навигации.
* Выбор папки для загрузки музыки и кнопка быстрого открытия в Проводнике.
* Переключатели функций: AMOLED тема, Discord RPC, вшивание обложек, сворачивание в трей при закрытии.
* Блокировка автоматического обновления (`No Auto-Update`) для защиты модификаций.
* Доступ к инструментам разработчика Chromium (DevTools) по клавише `F12` или `Ctrl + Shift + I`.
* Интерактивное окно истории изменений (Changelog), синхронизирующееся с GitHub в реальном времени.

### 🛡 Конфиденциальность и оптимизация
* Встроенная блокировка телеметрии и стрим-логгеров.
* Патчер контрольных сумм Electron ASAR для стабильного запуска без сбоев.
* Безопасный рендеринг DOM, защищающий от XSS через теги треков.
* Полная санитизация имён файлов и путей под файловую систему Windows.

## 🚀 Установка и запуск

### Вариант 1. Установщик (Setup)
1. Скачайте файл **`Yandex_Music_Mod_Setup.exe`** из раздела [Releases](https://github.com/KiryaScript/yamu-player/releases).
2. Запустите файл — приложение автоматически установится и создаст ярлык на рабочем столе и в меню «Пуск».

### Вариант 2. Портативная версия (Portable)
1. Скачайте архив **`Yandex_Music_Mod_Portable.zip`**.
2. Распакуйте в любую удобную папку и запустите **`Яндекс Музыка.exe`**.

## 🛠 Сборка из исходного кода

### Требования
* **ОС:** Windows 10 / 11 (x64)
* **Node.js:** версии 18.0.0 или новее
* **7-Zip:** (для сборки инсталлятора и архивов)

### Инструкция по сборке

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/KiryaScript/yamu-player.git
   cd yamu-player
   ```

2. Установите зависимости инструментов сборки:
   ```bash
   cd tools
   npm install
   cd ..
   ```

3. Запустите автоматическую сборку и патч контрольных сумм ASAR:
   ```bash
   node tools/build_and_patch.js
   ```

4. Запустите тесты для проверки целостности:
   ```bash
   node test/test_mod_suite.js
   ```
